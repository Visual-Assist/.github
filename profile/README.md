## First Look at Visual Assist

Visual Assist is for people who keep C++ they own in Visual Studio and want one named desk, not mixed tool windows. It gives you VS tools, own code, and a short path back to a C++ project you already run. It does not replace Visual Studio. It sits beside Visual Studio and keeps the helpers close.
